## 📊 宣传要点速查

### 太极 vs 主流框架的一句话差异

| 太极的回答 | 其他框架的回答 |
|-----------|--------------|
| "你的 Agent 应该能根据任务切换思维方式" | "我给你一个固定的模板" |
| "没有写死的 system prompt，每轮都是新的" | "你写好 prompt 我就不变了" |
| "工具是动态出现的，不是一开始就全给你" | "所有工具都注册好，自己挑" |
| "系统能越用越聪明，从经验中学习" | "每次从头开始" |

### 最独特的三个卖点

1. **「空」的哲学** — 没有固定提示词、没有固定工具集、没有固定认知库。每一轮都在重新编织
2. **八卦认知网格** — 八种认知姿态 + 五行生克关系，Weaver 根据生命周期切换姿态
3. **自我演化** — Anqu 分析日志 → 提炼模式 → 更新认知库 → 行为调整
