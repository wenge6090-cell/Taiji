# 【分享】太极（Taiji）Agent 架构：用《易经》哲学重塑 AI 认知循环

> 一个没有固定 system prompt、工具集动态加载、认知库能自我演化的 Agent 架构

## 太长不看版

最近在做一个开源的 AI Agent 架构实验，核心思想来自《易经》：

- **空** — 没有固定的 system prompt，每轮 Weaver 从八卦格栅动态编织
- **编织器（Weaver）** — 核心调度引擎，把认知格栅、技能工具、执行历史织成可用的提示词
- **六爻循环** — 明觉(含思变之责)→Weaver→Yang→Yin→Executor→暗驱(含路由决策)，形成一个完整的认知闭环
- **八卦认知网格** — 八种认知姿态（创造/执行/启动/分析/破局/评估/聚焦/表达），根据任务生命周期切换
- **自我演化** — Anqu 分析日志，提炼模式，更新认知库，系统越用越聪明

**开源仓库**：https://github.com/wenge6090-cell/Taiji

## 为什么做这个？

用过 AutoGPT、CrewAI、LangGraph 的朋友应该都发现了：它们的模式高度相似——固定 prompt + 固定工具集 + 固定循环。无论面对什么任务，Agent 的思维方式都一样。

但人类不是这样思考的：读论文时用分析模式，写代码时用创造模式，决策时用评估模式。**我们根据情境切换认知姿态。**

太极架构就是让 Agent 也能做到这一点。

## 空（Emptiness）不是什么都没有

太极的「空」不是缺失，而是**未定的可能性**：

| 领域 | 传统方式 | 太极的「空」 |
|------|---------|------------|
| system prompt | 固定不变 | 每轮动态编织，永不重复 |
| 工具集 | 写死的列表 | 每轮从八卦格栅动态加载 |
| 认知库 | 静态知识库 | 持续演化，永远有空间接纳新经验 |

## Weaver 在做什么？

Weaver（编织器）每轮做四件事：
1. **织认知策略** — 读八卦格栅，确定当前认知姿态（乾/坤/震/巽/坎/离/艮/兑）
2. **织工具** — 从八卦格栅发现关联技能，动态绑定可用工具
3. **织执行指导** — 把八卦的工作流注入提示词，告诉执行层用什么节奏
4. **织跨轮记忆** — 把上一轮结果编织进新一轮上下文

因为 Weaver 每一轮都在重新编织，所以系统永远不会被死板的模板锁死。
