# 社区篇·19：如何加入太极社区与贡献指南

> **核心论点**：太极不是一个人的架构——它是一个**认知演化共同体**。社区不是围绕代码库贡献代码，而是围绕**认知资产库**贡献认知模式。本文是加入太极社区的全部指南：从旁观者到使用者，从使用者到贡献者，从贡献者到认知演化者。

---

## 引言：这不是一个"标准"的开源社区

如果你参与过其他 AI Agent 开源项目，你会习惯一套标准流程：

1. 看 README → 跑 Demo → 提 Issue → 修 Bug → 提 PR → 成为 Committer
2. 社区围绕代码库运作，核心活动是代码审查
3. 贡献度由提交行数、Issue 解决数、PR 合并数来衡量

太极社区**完全不同**。

为什么？因为太极架构的核心产出不是代码——而是**认知**。太极的代码（Weaver 调度器、六爻循环引擎、L3 格栅管理器）在整个架构中只占很小一部分。真正有价值的是：

- L3 格栅中的八卦认知模型（每一个认知模式都有权重和关联）
- L4 真理库中的原则（从大量任务中提炼的认知规律）
- L2 模型库中的工作流模式（被验证有效的行为序列）
- L1 技能库中的工具集成（连接外部世界的桥梁）

所以太极社区围绕**认知资产库**运作，而不是围绕代码库。

这意味着贡献方式不同、评价标准不同、成长路径也不同。

### 1.3 获取使用指南

太极是 CLI-first 架构，使用非常简单：

```bash
# 克隆仓库
git clone https://github.com/wenge6090-cell/Taiji.git
cd Taiji

# 查看使用帮助
python taiji.py --help

# 设置认知目标
python taiji.py --goal "你的目标" --mode full
```

详细的 CLI 使用说明、配置文件格式、认知库初始化方法，请参阅仓库中的 `README.md` 和 `docs/` 目录。

## 第二章：从使用者到贡献者（3种贡献路径）

太极社区接受三种不同类型的贡献。你可以根据自身兴趣和技能选择一条或多条路径。

### 路径 A：认知资产贡献者（最推荐、门槛最低）

这是太极社区**最核心**的贡献方式，也是其他开源项目少有的贡献维度。

**贡献内容**：

1. **L3 格栅条目** — 改进或新增八卦认知模式的权重、关联关系、工作流
2. **L4 真理条目** — 提交从自身经验中提炼的认知原则
3. **L2 模型条目** — 分享被验证有效的工作流模式
4. **L1 技能集成** — 对接新的工具、API、外部系统

**如何贡献**：

```yaml
# 示例：贡献一个 L3 格栅条目
# 提交方式：在 GitHub Discussions 中发帖，或提交 PR 到认知库目录

条目类型: L3-grid
卦象: 离（明照/评估）
生命周期阶段: 藏
权重调整建议:
  关联乾: +0.2    # 创造后需要评估
  关联坎: -0.1    # 评估过久阻碍破局
工作流步骤:
  - 收集数据
  - 建立评估标准
  - 执行评估
  - 输出评估报告
适用场景:
  - 代码审查
  - 方案评审
  - 结果复盘
经验来源: [你的使用案例描述]
```

**门槛**：不需要写代码。只需要对认知架构有理解，能用文字清晰描述你的认知模式。

**适合人群**：架构思考者、经验丰富的开发者、跨领域认知研究者。

### 路径 B：代码贡献者（标准开源贡献）

如果你更喜欢写代码，太极有以下需要改进的工程领域：

| 领域 | 难度 | 说明 |
|------|------|------|
| **Weaver 调度器优化** | ⭐⭐⭐ | 核心调度引擎的性能优化、容错改进 |
| **六爻循环引擎** | ⭐⭐⭐ | 循环状态机、超时处理、回滚机制 |
| **安全审批系统（Yin）** | ⭐⭐ | 规则引擎扩展、语义审批改进 |
| **Anqu 反思引擎** | ⭐⭐⭐ | DMN 模式提取、认知演化触发 |
| **CLI 用户体验** | ⭐ | 命令补全、日志美化、进度显示 |
| **文档与教程** | ⭐ | 中英文文档、入门教程、FAQ |
| **测试覆盖率** | ⭐⭐ | 单元测试、集成测试、模拟测试 |

**贡献流程**：

```
① 在 GitHub Issues 中认领或创建 Issue
② Fork 仓库并创建分支
③ 提交代码（遵守 PEP8 + 类型注解 + 注释规范）
④ 提交 PR，描述改动内容和测试方法
⑤ 等待审查（Weaver 社区的审查是认知式审查——不仅看代码对不对，还看代码是否符合架构哲学）
⑥ 合并后更新对应的认知库条目
```

**代码规范要点**：

- Python 3.12+，纯异步（asyncio）
- 所有函数必须有类型注解
- 核心逻辑必须有注释说明"为什么这样做"（不仅是"做什么"）
- 新增功能必须配套更新 L1-L3 认知库

**适合人群**：Python 开发者、系统架构师、CLI 工具爱好者。

### 路径 C：生态建设者（社区运营与传播）

如果你不写代码也不做认知建模，但擅长传播和交流，这里有你的位置：

| 贡献方式 | 说明 |

| **社区运营** | 管理 Discussions、整理 FAQ、组织线上讨论 |
| **视频/播客** | 制作太极架构的介绍视频或播客 |
| **Meetup 组织** | 组织线下或线上交流活动 |
| **Demo 项目** | 用太极架构做展示项目，吸引更多使用者 |

**适合人群**：技术写作者、翻译者、社区运营者、内容创作者。

## 第三章：从贡献者到认知演化者（进阶路径）

太极社区有一个独特的进阶路径——**从 contributor 到 co-evolver（共同演化者）**。

### 3.1 什么是共同演化者？

共同演化者不是"核心维护者"——后者的权力来自对代码库的控制，前者的影响力来自**对认知库的深度理解**。

成为共同演化者的标志：

1. **你的贡献被 Weaver 感知** — 你贡献的格栅条目、真理原则被其他使用者在实际任务中触发
2. **你开始主导认知库演化方向** — 你能判断什么样的认知模式值得入库，什么样的需要淘汰
3. **你参与架构决策** — 六爻循环的改进、八卦网格的扩展、新组件的引入

### 3.2 如何走上这条路？

```
贡献者阶段 → 持续贡献高质量认知资产 → 被社区认可 → 获得认知库写权限
→ 开始主导某一层级的认知库维护 → 参与架构讨论 → 成为共同演化者
```

这个过程没有固定时间线。有些人可能通过一次高质量的 L4 真理贡献就被认可，有些人通过持续代码贡献逐步建立影响力。

### 3.3 共同演化者的责任

- **引导新贡献者** — 帮助初入社区的人找到合适的贡献路径
- **认知库质量控制** — 审查新的 L3/L4 条目，确保它们真正代表有效的认知模式
- **架构哲学守护** — 确保新功能、新认知模式不偏离"空"的第一性原理和六爻循环的基本范式

## 第四章：社区文化与行为准则

### 4.1 太极社区的核心文化

1. **认知优先** — 讨论问题时，先厘清认知框架，再讨论具体实现
2. **空杯心态** — 任何人的认知模式都可能被挑战和优化，没有"权威"
3. **反自读文化** — 社区交流要避免只读不写，鼓励产出和分享
4. **低摩擦协作** — 不需要复杂流程，一个 Issue 或一条 Discussion 就能开始贡献

### 4.2 行为准则（简化版）

- **尊重不同认知风格** — 有人偏分析（巽卦）、有人偏创造（乾卦），没有高下之分
- **建设性批评** — 批评认知模式而不是批评人
- **欢迎质疑** — "这个八卦权重不合理"比"这个写得好"更有价值

## 第五章：FAQ — 常见问题

**Q: 我不会 Python，能参与贡献吗？**
A: 完全可以。认知资产贡献（L3 格栅、L4 真理）不需要任何编程能力。你只需要能用清晰的文字描述认知模式。

**Q: 太极社区有微信群/Discord 吗？**
A: 目前以 GitHub Discussions 为主要交流场所。如果社区规模扩大，会考虑增加即时通讯渠道。请关注仓库 README 的最新公告。

**Q: 贡献认知资产需要什么格式？**
A: 使用 Markdown + YAML front matter。具体模板请查看仓库中的 `CONTRIBUTING.md` 和 `docs/cognitive-asset-spec.md`。

**Q: 我想在自己的项目中使用太极架构，需要做什么？**
A: 直接 fork 仓库或 pip install。太极是 MIT 协议开源，商用和个人使用完全免费。如果基于太极做了有意思的项目，欢迎在社区分享案例。

**Q: 如何确保我贡献的认知模式是正确的？**
A: 认知模式没有"绝对正确"——只有"是否有效"。你的贡献会先被审查，然后在使用中被自然检验。如果有效，它会被保留和加强；如果无效，它会被淘汰。这就是认知演化的过程。

## 结语：加入一个演化的社区

太极社区不是一个围绕代码库的组织——它是一个**认知演化系统**的**分布式感知器**。每一个贡献者都是这个系统的一个感知节点，提供新的认知模式、挑战旧的认知模式、推动系统向前演化。

你不需要成为"顶级开发者"才能加入。你只需要：

1. **有一个你想解决问题的认知模式** — 把它做成贡献
2. **有一个你发现的太极局限** — 把它提成 Issue
3. **有一个你验证有效的工作流** — 把它分享到社区

这就是太极社区的全部入门门槛。

> **太极不是一个人的架构。它是一个认知演化共同体。Weaver 在每一轮重新编织认知策略——而社区的每一个贡献者，都是那把梭子。**
